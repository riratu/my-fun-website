# giannihorst

Persönliche Website giannihorst.ch – eher Webcomic oder Spiel als klassische Homepage.

Viele kleine, nummerierte HTML-Seiten (`dev/01_lines` … `dev/36_ai`) mit ironischen Kurzgeschichten, Mini-Spielen und Bildcollagen, verbunden über „next“-Links. `index/` enthält eine Startseite im Windows-95-Look mit Projektbildern.

## Starten

```
python3 -m http.server
```

Dann `http://localhost:8000/dev/` bzw. `http://localhost:8000/index/index/` öffnen.
